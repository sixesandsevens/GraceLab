Client Setup Guide

Follow these steps to provision a new lab workstation. Complete Step 1 first (you need the token before running the installer).

1 Register the Station

In the Stations section, click Register Station and fill in the hostname and display name for the new machine. Submit the form — the one-time token will be shown on the next screen. Copy it before navigating away.

Register Station →

The hostname must exactly match the machine's actual hostname (e.g. LAB-PC-01). The token is shown only once — if you lose it, rotate a new one from the station detail page.
2 Clone the Repo onto the New Machine

On the new workstation, open a terminal and clone the GraceLab repository:

git clone https://github.com/sixesandsevens/GraceLab.git && cd GraceLab
The machine needs git installed (sudo apt install git). Alternatively, copy the repo folder from another station via USB or scp.
3 Run the Installer

From inside the cloned repo, run the installer as root. Replace LAB-PC-01 with the actual hostname and paste the token from Step 1: 

sudo ./tools/install-client.sh \
  --server-url {{ server_url }} \
  --hostname   LAB-PC-01 \
  --token      PASTE-TOKEN-HERE

The installer will:

  • Create gracelab and guestlab system users
  • Install the client to /opt/gracelab-client/
  • Write /etc/gracelab/client_config.ini
  • Configure LightDM autologin and XFCE kiosk lockdown
  • Apply Firefox policies and terminal blocks
The installer must be run from the root of the GraceLab repo. It requires python3 and will install python3-tk and rsync automatically if missing.
4 Reboot and Verify

Reboot the machine. LightDM will autologin as gracelab and the kiosk screen should appear fullscreen.

sudo reboot

After reboot, check the Stations dashboard — the new station should appear online within 30 seconds once it reaches the server.

If the station shows Offline, confirm it is on the correct network and can reach {{ server_url }}. Also verify the hostname in /etc/gracelab/client_config.ini matches what was registered in Step 1.
